UC1 – Lebensmittel-Katalog verwalten

Verwaltung der Lebensmittel-Stammdaten mit CRUD-Operationen

← Zurück zur Übersicht

📋 Übersicht

UC1 bildet die Basis des FoodDatabase-Systems. Mit diesem Use-Case können Lebensmittel in den Katalog aufgenommen, aktualisiert, gelesen und gelöscht werden (CRUD-Operationen).

Der Lebensmittel-Katalog wird von nahezu allen anderen Use-Cases benötigt, da ProduktInstanzen, Nährwerte und Rezepte auf Lebensmittel-Daten verweisen.

🏗️ Domain Model

Entität: LebensmittelKatalog

Feld Typ Beschreibung
Id int (PK) Eindeutige Lebensmittel-ID
Name string Lebensmittel-Name (z.B. "Milch", "Käse")
Einheit string Maßeinheit: g, ml, oder Stück
Kategorie string Optional: Lebensmittel-Kategorie (z.B. "Milchprodukte")
ErstelltAm DateTime Zeitstempel der Erstellung

🔄 Workflows

Happy Path: Lebensmittel hinzufügen

  1. Benutzer öffnet "Lebensmittel verwalten" Seite
  2. Klickt "Neues Lebensmittel"
  3. Gibt Daten ein: Name="Milch", Einheit="ml", Kategorie="Milchprodukte"
  4. System speichert Lebensmittel in DB
  5. Lebensmittel erscheint in Liste

Alternative: Lebensmittel aktualisieren

  1. Benutzer sucht Lebensmittel in Liste
  2. Klickt "Bearbeiten"
  3. Ändert Daten (z.B. Kategorie)
  4. System speichert Änderungen
