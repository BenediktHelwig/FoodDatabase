UC3: Nährwerte verwalten

Use-Case 3 | Status: ⏳ TODO

📋 Übersicht

Beschreibung: CRUD für Nährwerte pro Lebensmittel (pro 100g/ml). Benutzer kann Nährwertinformationen eingeben und verwalten.

Hauptziele

  • Nährwerte pro Lebensmittel hinzufügen (Kcal, Eiweiß, Fett, Kohlenhydrate)
  • Nährwerte bearbeiten und aktualisieren
  • Nährwerte löschen

Geschäftsnutzen

Basis für UC5 (Rezept-Nährwerte berechnen). Der Benutzer kann Rezepte erstellen und automatisch Nährwertinformationen berechnen.

📦 Domain Model

Beteiligte Entities

Entity Rolle Beziehung
Nährwert Zu verwaltende Nährwertinformation Primary (CRUD-Ziel)
LebensmittelKatalog Referenziertes Lebensmittel Foreign Key (1..1)

Neue Attribute

Nährwert
├── LebensmittelKatalogId: int (FK)
├── Kcal: decimal (pro 100g/ml)
├── EiweißGramm: decimal
├── FettGramm: decimal
├── KohlenhydrateGramm: decimal
├── FaserGramm: decimal
└── ZuckerGramm: decimal

🔄 User Workflows

Hauptworkflow: Nährwert erstellen

1. Benutzer wählt Lebensmittel aus
2. Klickt "Nährwert hinzufügen"
3. Gibt Nährwertinformationen ein
4. Klickt "Speichern"
5. System validiert Werte
6. System speichert in DB
7. Nährwert wird angezeigt

Weitere Workflows

Bearbeiten: Benutzer ändert Nährwertinformationen

Löschen: Benutzer entfernt Nährwertinformationen

🔌 Service Interface

Service-Methoden

public interface INährwertService
{
    Task<Nährwert> CreateNährwertAsync(Nährwert nährwert);
    Task<Nährwert> GetNährwertByIdAsync(int id);
    Task<Nährwert> GetNährwertByLebensmittelAsync(int lebensmittelId);
    Task<Nährwert> UpdateNährwertAsync(Nährwert nährwert);
    Task<bool> DeleteNährwertAsync(int id);
}
