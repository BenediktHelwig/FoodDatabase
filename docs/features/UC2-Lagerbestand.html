UC2: Lagerbestand aktualisieren

Use-Case 2 | Status: ⏳ TODO

📋 Übersicht

Beschreibung: Benutzer kann Menge und Lagerort von Produktinstanzen aktualisieren. Dies ist zentral, um den aktuellen Bestand zu verwalten.

Hauptziele

  • Menge von Produktinstanzen ändern
  • Lagerort zuordnen (z.B. Kühlschrank, Vorratsschrank)
  • Sofortige Aktualisierung im System

Geschäftsnutzen

Der Benutzer kann seinen aktuellen Lagerbestand verwalten und jederzeit sehen, wie viel von welchem Produkt an welchem Ort vorhanden ist.

📦 Domain Model

Beteiligte Entities

Entity Rolle Beziehung
ProduktInstanz Zu aktualisierende Einheit Primary (Update-Ziel)
Lagerort Speicherort des Produkts Foreign Key (0..1)
LebensmittelKatalog Referenzen das Produkt Foreign Key (1..1)

Betroffene Attribute

ProduktInstanz
├── Menge: decimal
├── Einheit: string (g, ml, Stück, etc.)
└── Lagerort: Lagerort (Foreign Key)

🔄 User Workflows

Hauptworkflow: Bestand aktualisieren

1. Benutzer öffnet ProduktInstanz-Liste
2. Selektiert eine ProduktInstanz
3. Ändert Menge und/oder Lagerort
4. Klickt "Speichern"
5. System validiert Eingaben
6. System speichert Änderungen in DB
7. Benutzer sieht Erfolgsmeldung

Alternative Flows

Fehler: Ungültige Menge - System zeigt Validierungsfehler und verhindert Speichern

Lagerort nicht gefunden - System zeigt Dropdown mit verfügbaren Lagerorten
