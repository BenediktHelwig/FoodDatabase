UC7: Verfallsdatum-Warnungen

Use-Case 7 | Status: ⏳ TODO

📋 Übersicht

Beschreibung: Überwachung von Verfallsdaten mit automatischen Warnungen. Produkte werden mit 🟡 Gelb (bald verfallen) oder 🔴 Rot (verfallen) gekennzeichnet.

Hauptziele

  • MHD von ProduktInstanzen überwachen
  • Gelbe Warnung: X Tage vor MHD
  • Rote Warnung: MHD überschritten
  • Dashboard-Anzeige mit Warnung-Status

Geschäftsnutzen

Der Benutzer kann schnell sehen, welche Produkte bald verfallen oder bereits abgelaufen sind, um Verschwendung zu vermeiden.

📦 Domain Model

Beteiligte Entities

Entity Rolle Beziehung
ProduktInstanz Zu überwachend (mit MHD) Primary (Monitor)
VerfallsdatumWarnung Status-Tracking Child (1:1)

Neue Entity: VerfallsdatumWarnung

VerfallsdatumWarnung
├── ProduktInstanzId: int (FK)
├── Status: WarningStatus (Green, Yellow, Red)
├── TageVerbleibend: int
├── LastCheckedAt: DateTime
└── NotifiedAt: DateTime (nullable)

enum WarningStatus
{
    Green = 0,    // Mehr als X Tage
    Yellow = 1,   // X Tage oder weniger
    Red = 2       // Verfallen
}

🔄 User Workflows

Hauptworkflow: Dashboard anzeigen

1. Benutzer öffnet Dashboard/Übersicht
2. System berechnet Status für alle ProduktInstanzen
   - Vergleicht Heute mit MHD
   - Setzt Status (Green/Yellow/Red)
3. Zeigt Warnungen visuell an:
   🟢 Grün: OK
   🟡 Gelb: Bald verfallen (z.B. 3 Tage)
   🔴 Rot: Verfallen (MHD < Heute)
4. Benutzer kann auf Warnung klicken → Details

Fehlerfall

MHD nicht vorhanden: System zeigt keine Warnung (oder Neutral)

🔌 Service Interface

Service-Methoden

public interface IVerfallsdatumService
{
    Task<WarningStatus> GetWarningStatusAsync(int produktInstanzId);
    Task<List<ProduktInstanzWarning>> GetAllWarningsAsync();
    Task<List<ProduktInstanzWarning>> GetYellowWarningsAsync();
    Task<List<ProduktInstanzWarning>> GetRedWarningsAsync();
    Task RefreshAllWarningsAsync();
}

public class ProduktInstanzWarning
{
    public int ProduktInstanzId { get; set; }
    public string ProduktName { get; set; }
    public DateTime MHD { get; set; }
    public WarningStatus Status { get; set; }
    public int TageVerbleibend { get; set; }
}
