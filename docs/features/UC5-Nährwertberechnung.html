UC5: Nährwerte berechnen

Use-Case 5 | Service: ✅ FERTIG (18/21 Tests GRÜN) | UI: ✅ in Rezept-Detail eingebettet

📋 Übersicht

Beschreibung: Automatische Berechnung der Gesamtnährwerte eines Rezepts basierend auf Zutaten und deren Nährwertinformationen.

Hauptziele

  • Nährwerte automatisch berechnen (nicht manuell eingeben)
  • Berechnung basierend auf Zutat-Mengen
  • Anzeige der Gesamtnährwerte pro Rezept

Geschäftsnutzen

Der Benutzer kann schnell sehen, wie viele Kcal und welche Nährwerte sein Rezept hat, ohne manuell zu rechnen.

📦 Domain Model

Beteiligte Entities

Entity Rolle Beziehung
Rezept Quell-Rezept Primary (Read)
RezeptZutat Zutat + Menge Child (Read)
Nährwert Zutat-Nährwertinformation Reference (Read)

Berechnung

Gesamtnährwerte = SUMME über alle Zutaten:
  pro Zutat:
    Kcal = (Nährwert.Kcal / 100) * RezeptZutat.Menge
    Eiweiß = (Nährwert.Eiweiß / 100) * RezeptZutat.Menge
    etc.

🔄 User Workflows

Hauptworkflow: Nährwerte ansehen

1. Benutzer öffnet Rezept-Detail (/rezepte/{id})
2. System berechnet automatisch Nährwerte
3. Nährwerte werden angezeigt (Kcal, Eiweiß, Fett, KH)
4. Benutzer sieht auch Werte pro Portion (falls definiert)
5. Benutzer ändert die Portionen (+/- oder Eingabefeld); die Werte werden über AdjustNährwerteForPortionAsync neu berechnet

Fehlerfall

Fehlende Nährwertinformation: Wenn Zutat keine Nährwerte hat, wird Warnung angezeigt

🖥️ UI-Anzeige (eingebettet in Rezept-Detail)

Status: ✅ live unter /rezepte/{id} (WP5 Teil 1)

Die Anzeige ist eingebettet und durch bUnit-Tests abgedeckt.

Komponente und Parameter

RezeptNährwertAnzeige.razor (src/App/Components/) wird in RezeptDetail.razor eingebettet:

  • RezeptId (int): Rezept, dessen Nährwerte geladen werden
  • Portionen (int, neu): Rezept-Portionen; Startwert der Portionsanpassung (mindestens 1)

Ohne Zutaten wird die Komponente nicht eingebettet. Die Detailseite zeigt stattdessen den Hinweis „Noch keine Zutaten – Nährwerte werden berechnet, sobald Zutaten erfasst sind.“, damit keine falschen Nullwerte erscheinen.

Fehler beim Laden erscheinen in einem Alert mit role="alert".

Portionen-Fix

Bisher stand die Portionsanpassung fest auf 4, unabhängig vom Rezept. Der Service rechnet aber mit rezept.Portionen. Bei einem Rezept mit 2 Portionen zeigte das Eingabefeld deshalb 4, und der erste Klick auf „+“ berechnete für 5 Portionen statt für 3. Jetzt startet die Anzeige mit dem Parameter Portionen. Am Service hat sich nichts geändert.

🔌 Service Interface

Service-Methoden

public interface IRezeptNährwertService
{
    Task<RezeptNährwertErgebnis> CalculateRezeptNährwerteAsync(int rezeptId);
    Task<RezeptNährwertErgebnis> CalculateRezeptNährwerteAsync(Rezept rezept);
}

public class RezeptNährwertErgebnis
{
    public int RezeptId { get; set; }
    public decimal GesamtKcal { get; set; }
    public decimal GesamtEiweißGramm { get; set; }
    public decimal GesamtFettGramm { get; set; }
    public decimal GesamtKohlenhydrateGramm { get; set; }
    public List<string> FehlendNährwertZutaten { get; set; }
}
