UC8: Einkaufslisten generieren

Use-Case 8 | Status: ⏳ TODO

📋 Übersicht

Beschreibung: Automatische Generierung von Einkaufslisten basierend auf Mindestbestandsgrenzen. Wenn Menge eines Produkts unter Grenzwert fällt, wird es zur Einkaufsliste hinzugefügt.

Hauptziele

  • Mindestbestand pro Lebensmittel definieren
  • Automatisch Einkaufslisten generieren
  • Einkaufte Produkte abhaken/erfassen

Geschäftsnutzen

Der Benutzer sieht automatisch, welche Produkte zum Einkaufen notwendig sind. Keine manuelle Liste erforderlich.

📦 Domain Model

Beteiligte Entities

Entity Rolle Beziehung
Einkaufsliste Zu verwaltende Liste Primary (CRUD)
EinkaufslisteEintrag Item in der Liste Child (1:N)
LebensmittelKatalog Referenziertes Produkt Foreign Key

Neue Attribute

LebensmittelKatalog
├── ... (existing)
└── MindestbestandMenge: decimal (NEW)

Einkaufsliste
├── Name: string
├── ErstelltAm: DateTime
├── Status: ListStatus (Open, Completed)
└── Einträge: ICollection<EinkaufslisteEintrag>

EinkaufslisteEintrag
├── EinkaufslisteId: int (FK)
├── LebensmittelKatalogId: int (FK)
├── EmpfohlenenMenge: decimal
└── Gekauft: bool

🔄 User Workflows

Hauptworkflow: Einkaufsliste generieren

1. Benutzer klickt "Einkaufsliste generieren"
2. System prüft alle Lebensmittel:
   - Aktuelle Menge < Mindestbestand? → In Liste
3. System zeigt generierte Liste
4. Benutzer kann Mengen anpassen
5. Benutzer speichert Liste
6. Beim Einkaufen: Abhaken wenn gekauft

Alternative Flows

Manuelle Erstellung: Benutzer erstellt Liste manuell

Listen-Template: Vorgespeicherte Listen (z.B. "Wöchentlicher Einkauf")
