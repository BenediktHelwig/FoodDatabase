UC9: Lagerorte verwalten

Use-Case 9 | Status: ⏳ TODO

📋 Übersicht

Beschreibung: CRUD für Lagerorte (z.B. Kühlschrank, Vorratsschrank, Gefrierraum). Benutzer kann Speicherorte für Produkte definieren.

Hauptziele

  • Lagerorte erstellen (z.B. "Kühlschrank", "Gefrierschrank")
  • Lagerorte bearbeiten und löschen
  • Lagerorte bei Produktinstanzen referenzieren

Geschäftsnutzen

Der Benutzer kann sein Lager in verschiedene Bereiche unterteilen (Küche, Keller, etc.) und immer sehen, wo welche Produkte lagern.

📦 Domain Model

Beteiligte Entities

Entity Rolle Beziehung
Lagerort Zu verwaltender Speicherort Primary (CRUD-Ziel)
ProduktInstanz Referenzierendes Produkt Child (0:N)

Neue Entity: Lagerort

Lagerort
├── Id: int (PK)
├── Name: string (z.B. "Kühlschrank")
├── Beschreibung: string (optional)
├── Temperatur: decimal (optional, in °C)
├── Lagertyp: LagerortTyp (Kühlschrank, Gefrierschrank, Schrank, etc.)
└── ProduktInstanzen: ICollection<ProduktInstanz>

enum LagerortTyp
{
    Kühlschrank,
    Gefrierschrank,
    Schrank,
    Regal,
    Sonstiges
}

🔄 User Workflows

Hauptworkflow: Lagerort erstellen

1. Benutzer öffnet "Lagerorte verwalten"
2. Klickt "Neuer Lagerort"
3. Gibt Name und Typ ein (z.B. "Kühlschrank")
4. Speichert
5. Lagerort kann jetzt bei ProduktInstanzen verwendet werden

Weitere Workflows

Bearbeiten: Benutzer ändert Lagerort-Informationen

Löschen: Benutzer entfernt Lagerort (nur wenn keine Produkte zugeordnet)

🔌 Service Interface

Service-Methoden

public interface ILagerortService
{

    Task<Lagerort> GetLagerortByIdAsync(int id);

    Task<Lagerort> UpdateLagerortAsync(Lagerort lagerort);
    Task<bool> DeleteLagerortAsync(int id);

}
