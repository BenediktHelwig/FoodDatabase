UC6: Verbrauch ausbuchen

Use-Case 6 | Status: ⏳ TODO

📋 Übersicht

Beschreibung: Benutzer kann verbrauchte Produkte ausbuchen (reduziert Menge oder markiert als verbraucht). Unterstützt sowohl Scan als auch manuelle Eingabe.

Hauptziele

  • Menge von ProduktInstanz reduzieren
  • Produkt als vollständig verbraucht markieren
  • Verbrauch per Barcode-Scan oder manuell eingeben

Geschäftsnutzen

Der Benutzer kann schnell und einfach erfassen, was verbraucht wurde. Dies aktualisiert den Lagerbestand automatisch.

📦 Domain Model

Beteiligte Entities

Entity Rolle Beziehung
ProduktInstanz Zu verbrauchende Einheit Primary (Update-Ziel)
LebensmittelKatalog Produkt-Template Reference (Read)

Aktion

Verbrauch ausbuchen:
  Input: ProduktInstanz + Verbrauchte Menge
  Action: ProduktInstanz.Menge -= Verbrauchte Menge
  Result: Wenn Menge <= 0, markiere als "verbraucht"

🔄 User Workflows

Workflow 1: Manuelle Eingabe

1. Benutzer öffnet "Verbrauch ausbuchen"
2. Wählt Produkt/ProduktInstanz
3. Gibt verbrauchte Menge ein
4. Klickt "Ausbuchen"
5. System reduziert Bestand
6. Bestätigung wird angezeigt

Workflow 2: Barcode-Scan

1. Benutzer öffnet Scan-Funktion
2. Scannt Barcode von ProduktInstanz
3. System identifiziert Produkt
4. Benutzer gibt Menge ein (oder "alles verbraucht")
5. System reduziert Bestand

Fehlerfall

Zu viel ausgebucht: System zeigt Warnung, wenn Menge > verfügbar
