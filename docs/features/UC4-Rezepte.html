UC4: Rezepte verwalten

Use-Case 4 | Status: ⏳ TODO

📋 Übersicht

Beschreibung: CRUD für Rezepte und deren Zutaten-Liste. Benutzer kann Rezepte erstellen, bearbeiten, löschen.

Hauptziele

  • Rezepte mit Namen und Beschreibung erstellen
  • Zutaten-Liste pro Rezept verwalten
  • Mengen pro Zutat angeben
  • Rezepte bearbeiten und löschen

Geschäftsnutzen

Basis für UC5 (automatische Nährwertberechnung). Der Benutzer kann seine Lieblings-Rezepte speichern und verwalten.

📦 Domain Model

Beteiligte Entities

Entity Rolle Beziehung
Rezept Hauptentität (zu verwalten) Primary (CRUD-Ziel)
RezeptZutat Zutat im Rezept Child (1:N)

🔄 User Workflows

Hauptworkflow: Rezept erstellen

1. Benutzer klickt "Neues Rezept"
2. Gibt Rezept-Name und Beschreibung ein
3. Fügt Zutaten hinzu (Lebensmittel + Menge)
4. Kann weitere Zutaten hinzufügen
5. Klickt "Speichern"
6. System speichert Rezept + Zutaten
7. Rezept wird in Liste angezeigt

Weitere Workflows

Bearbeiten: Benutzer ändert Rezeptinformationen und Zutaten

Löschen: Benutzer entfernt Rezept

🔌 Service Interface

Service-Methoden

public interface IRezeptService
{
    Task<Rezept> CreateRezeptAsync(Rezept rezept);

    Task<Rezept> UpdateRezeptAsync(Rezept rezept);
    Task<bool> DeleteRezeptAsync(int id);
    Task AddZutatToRezeptAsync(int rezeptId, RezeptZutat zutat);
    Task RemoveZutatFromRezeptAsync(int rezeptId, int zutatId);
}
